# Foundry (`foundry-skill`)

**One skill to decide what to build, design it without AI slop, engineer the invisible details, and verify it in a real browser.**

Most AI agent skills only solve one slice of product building: either they critique business ideas, generate generic UI templates, tweak animations, or click around a browser. **Foundry** merges **9 open-source agent ecosystems (315 files)** into a single unified operating system for Claude Code, Google Antigravity, Cursor, and Codex:

1. **The Boardroom (Strategy & Offers)** — *Roast Room + Newroaster*: A 12-seat adversarial council built from verbatim public work (Jeff Bezos, Paul Graham, Alex Hormozi, Warren Buffett, Naval Ravikant, Elon Musk, Sara Blakely, GaryVee, Dan Martell, Gino Wickman, Codie Sanchez, Leila Hormozi) that debates your pricing, positioning, and product bets across 3 scored rounds with Ruin Cap and One-Way Door overrides.
2. **The Design Studio (UX, Taste & Anti-Slop)** — *ui-ux-ultra-max + Impeccable + taste-skill 2.5 + Unslop*: Persona-driven architecture, 4 Surface Modes (`Persuade`, `Operate`, `Read`, `Experience`), 6 Business Kinds, 21 refinement verbs (`/polish`, `/distill`, `/harden`, `/overdrive`), a strict 9-pass redline unslopping pipeline (`Spacing → Color → Icons → Copy → Type → Layout → Details → Visuals → Motion`), and a 6-member independent Design Review Council.
3. **The Engineering Forge (Motion, 3D & Tokens)** — *Emil Kowalski's Design Engineering + ultra-frontend + ultra-ui-ux-pro-max*: Frequency-based animation laws (`100+/day = 0ms`, `<300ms` overlays), custom cubic-bezier and spring physics, origin-aware popovers, `clip-path` transitions, Three.js/WebGL & GSAP scroll choreography, 260 searchable design systems, 320 fonts, exact WCAG 2.2 contrast math (`contrast.py`), and a 5-platform token compiler (`export_tokens.py`).
4. **The Verification Lab (Code-as-Action Browser QA)** — *Microsoft CUAWright / Webwright*: Turns every requirement into a Critical Point checklist (`plan.md`), explores live DOM state via `aria_snapshot()`, writes deterministic Playwright scripts (`final_runs/run_<id>/final_script.py`), verifies every state against real screenshots, and distills flows into zero-token reusable CLI tools (`/cuawright:craft`).
